# LUMÉ — Salon & Beauty

### Future Interns | UI/UX Design Internship | Task 1

LUMÉ is a salon and beauty website concept designed to create a smoother digital experience for discovering services, building trust, and booking appointments.

## Project Overview

This project was created as part of my UI/UX Design Internship at Future Interns.

The main focus was to design a clear and user-friendly appointment booking experience for a salon website.

## Problem

Customers often face difficulty understanding salon services, pricing, stylist information, and the booking process.

## Solution

LUMÉ introduces a structured experience where users can:

1. Select gender
2. Choose a service
3. Select a stylist
4. Choose a date
5. Choose a time
6. Enter their details
7. Confirm the appointment

## Key UX Decisions

- Clear service pricing and duration
- Structured service categories
- Stylist profiles with ratings and expertise
- Reviews and gallery to build trust
- Step-by-step booking flow
- Clear calls to action
